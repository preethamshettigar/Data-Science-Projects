# 🚗Car Insurance Claim Data

## About the dataset

The dataset used for this project was sourced from: https://www.kaggle.com/datasets/xiaomengsun/car-insurance-claim-data

* The data includes around 8000 records of car insurance policyholders. This includes features such as their age, income, gender, claim hisory and more.
* The data include 2 target variables: A binary value on whether a claim has occured, and a claim amount given that the claim has occured.

### Objective

In this notebook, we will explore the steps in 2 parts 
- **Classification** for predicting if a claim has occured
- **Regression** for predicting the value of a claim assuming a claim has been made.
